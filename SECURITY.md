# Security policy

## Supported versions

Security fixes are made on the latest commit on `main`. Releases will declare their supported versions when versioned releases begin.

## Reporting a vulnerability

Do not disclose suspected secret leakage or a redaction bypass in a public issue.

Use GitHub's private security advisory flow for this repository. Include a minimal synthetic reproduction, the cfgredact version or commit, expected result, actual result, and any relevant configuration. Do not include real credentials or customer data.

We will acknowledge a report within five business days and coordinate a fix and disclosure timeline with the reporter.
